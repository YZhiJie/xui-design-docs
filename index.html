主题

XUI跨框架组件库

一套核心契约，Vue 3 与 React 19 双端同构的通用组件库

组件文档
主题定制

单一契约 @xui-design/core

ComponentSpec 是双端唯一合同，Props / Events / Slots 由契约层定义，适配层不得新增分歧。

Vue / React 双端同构

同名组件、同 API 口径：Vue 事件 ↔ React 回调、Vue 插槽 ↔ React renderXxx 一一映射。

样式单一来源

@xui-design/styles 统一输出 BEM 类名与 CSS 变量主题，双端零样式漂移。

核心逻辑单份实现

@xui-design/shared 承载状态与交互逻辑，双端只做薄适配；TypeScript 严格模式全量类型贯通。

安装

Shell
pnpm add @xui-design/vue @xui-design/styles

# 如需直接引用契约类型（TableColumn 等），再安装类型包
pnpm add @xui-design/core

# 应用入口引入一次样式
# main.ts:  import '@xui-design/styles'

快速开始

Vue
<script setup lang="ts">
import { Button } from '@xui-design/vue';
import '@xui-design/styles';
</script>

<template>
  <Button type="primary">Hello XUI</Button>
</template>

组件总览

基础组件

按钮 Button

基础按钮组件，支持多种语义类型、尺寸、加载与禁用状态。

输入框 Input

基础文本输入框，支持受控 / 非受控、清除按钮、前后缀与多种原生类型。

对话框 Modal

模态对话框，承载需要用户明确处理的信息或操作；支持焦点陷阱 / 焦点恢复、自定义底部文案与受控、ref 命令式两种用法。

抽屉 Drawer

从屏幕边缘滑出的抽屉面板，承载表单、详情等次级内容；支持四个方向、自定义尺寸、焦点陷阱 / 焦点恢复与 ref 命令式控制。

表单交互

开关 Switch

布尔值开关选择器，支持受控 / 非受控双模式与加载态。

复选框 Checkbox

在一组可选项中进行多选，或单独使用表示两种状态的切换，支持半选态。

单选框 Radio

在一组互斥选项中选择一个，由 RadioGroup 管理选中值，Radio 作为子项；也支持 options 数组配置。

下拉选择 Select

从弹出的选项面板中选择值，支持单选 / 多选 / 可搜索 / 虚拟滚动，键盘操作与 ARIA 语义完整。

日期选择 DatePicker

点击弹出月历面板选择单个日期，值统一为 YYYY-MM-DD 字符串，零日期依赖。

数字输入框 InputNumber

通过步进按钮或直接键入输入数字，自动完成范围收敛、步长对齐与精度处理。

表单 Form

功能完整的表单容器组件，支持字段注册、同步/异步校验、跨字段关联、条件校验、动态增删字段，以及禁用/只读/标签布局等场景。

级联选择 Cascader

从逐级展开的树形选项中选择一条路径，支持选到叶子或任意层级即触发。

时间选择 TimePicker

从时 / 分 / 秒三列面板中选择时间，值为 HH:mm:ss 格式字符串，支持步长与格式配置。

文件上传 Upload

通过点击选择文件并上传，支持多文件、数量 / 大小限制、图片列表展示与上传前校验。

数据展示

标签 Tag

用于标记和分类的小型标签，支持五种语义类型、两种尺寸与可关闭交互。

进度条 Progress

展示任务进度百分比，支持线性与环形两种形态及成功 / 失败状态色。

徽标数 Badge

以角标形式展示消息数量或状态红点，可包裹任意内容，也可独立使用。

头像 Avatar

展示用户或事物的图片 / 文字头像，支持三种尺寸、圆形方形与图片失败回退。

空状态 Empty

空数据 / 无结果时的占位展示，内置默认插画，支持自定义描述、插画与操作区。

骨架屏 Skeleton

数据加载中的占位屏，在内容就绪前提供结构感知，支持头像占位与自定义行数。

表格 Table

结构化数据表格，支持列定义、非受控排序、行选择、虚拟滚动、自定义单元格与空态。

树形控件 Tree

以树形结构展示层级数据，支持展开/收起、单选选中与级联勾选。

导航布局

标签页 Tabs

在同一区域切换多个平级内容面板，配置化标签项，支持受控 / 非受控与键盘切换。

分页 Pagination

数据分页导航，页码从 1 开始，自动计算总页数并收敛越界操作。

面包屑 Breadcrumb

显示当前页面层级路径，支持链接项 / 可点击项与自定义分隔符。

反馈提示

警告提示 Alert

静态内嵌的提示横幅，用于展示需用户关注的信息，支持四种语义、图标与关闭。

全局提示 Message

命令式全局轻提示，双端同构 API，首次调用自动挂载容器，无需预置组件。

文字提示 Tooltip

鼠标悬停或聚焦时展示的简单文字气泡，CSS 包裹定位（非 portal），支持四方位与两种触发。

加载中 Spin

加载状态指示器，可独立使用，也可包裹内容以遮罩形式表示区块加载。

气泡确认 Popconfirm

点击元素弹出轻量确认气泡，适合"删除"等需要二次确认但不必打断整页的操作。
