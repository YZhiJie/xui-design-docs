按钮 Button 基础组件 ​

基础按钮组件，支持多种语义类型、尺寸、加载与禁用状态。

功能特性 ​

  • 四种语义类型：default / primary / danger / link
  • 三种尺寸：sm / md（默认）/ lg
  • disabled 禁用、loading 加载态（加载中点击被忽略）
  • block 块级按钮（宽度撑满容器）
  • 前置图标与加载图标均可通过插槽 / 回调自定义

使用场景 ​

  • 表单提交、操作触发、导航跳转等一切需要点击交互的场景。

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

按钮类型 ​

通过 type 指定语义类型，默认 default。

Vue
<script setup lang="ts">
import { Button } from '@xui-design/vue';
</script>

<template>
  <div class="demo-row">
    <Button>Default</Button>
    <Button type="primary">Primary</Button>
    <Button type="danger">Danger</Button>
    <Button type="link">Link</Button>
  </div>
</template>

尺寸与块级 ​

sm / md / lg 三档尺寸；block 使按钮宽度撑满父容器。

Vue
<script setup lang="ts">
import { Button } from '@xui-design/vue';
import { isZh } from '../../../i18n';
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button size="sm">Small</Button>
      <Button size="md">Medium</Button>
      <Button size="lg">Large</Button>
    </div>
    <Button block>{{ isZh() ? 'Block（宽度撑满容器）' : 'Block (full width)' }}</Button>
  </div>
</template>

禁用与加载 ​

disabled 完全禁用交互；loading 时显示加载图标且点击被忽略，适合异步提交场景。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Button } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const loading = ref(false);
const submit = () => {
  loading.value = true;
  setTimeout(() => {
    loading.value = false;
  }, 1500);
};
</script>

<template>
  <div class="demo-row">
    <Button disabled>Disabled</Button>
    <Button loading>Loading</Button>
    <Button type="primary" :loading="loading" @click="submit">
      {{
        loading
          ? isZh()
            ? '提交中...'
            : 'Submitting...'
          : isZh()
            ? '点击模拟提交'
            : 'Click to submit'
      }}
    </Button>
  </div>
</template>

注意事项 ​

  • loading 状态下点击事件被忽略，避免异步提交期间重复触发。
  • type="link" 仅表现为链接样式，语义仍是 button 元素；需要原生导航请自行包裹 <a>。

无障碍 ​

  • 渲染为原生 <button>，disabled / loading 时携带 disabled 属性，键盘与读屏行为与原生按钮一致。
