下拉选择 Select 表单交互 ​

从弹出的选项面板中选择值，支持单选 / 多选 / 可搜索 / 虚拟滚动，键盘操作与 ARIA 语义完整。

功能特性 ​

  • 受控 / 非受控双模式，Vue 端支持 v-model:value
  • multiple 多选：选中值为 string[]，点击选项切换选中且面板不关闭，tag 可单独移除
  • searchable 可搜索：面板顶部搜索框按选项文案过滤（大小写不敏感）
  • virtual 虚拟滚动：1000+ 选项仅渲染可视窗口，maxHeight 控制面板视口高度
  • clearable 已选中时显示清空按钮（多选清空全部）；disabled 整体禁用
  • 键盘支持：上下方向键移动高亮（跳过禁用项）、Enter 确认、Esc 关闭
  • 分组选项：options 支持 SelectOptionGroup 混合结构，分组内选项统一展示

使用场景 ​

  • 选项数量较多、不适合用 Radio 平铺的单选 / 多选表单字段。
  • 选项上千条的大数据量选择场景（配合 virtual 虚拟滚动）。
  • 需要按文案快速定位选项的检索式选择场景（配合 searchable）。

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

受控与清空 ​

options 中可对单项设置 disabled；clearable 支持一键清空。

Vue
<script setup lang="ts">
import { ref, computed } from 'vue';
import { Select } from '@xui-design/vue';
import type { SelectOption } from '@xui-design/core';
import { isZh } from '../../../i18n';

const value = ref('');
const options = computed<SelectOption[]>(() =>
  isZh()
    ? [
        { label: '北京', value: 'beijing' },
        { label: '上海', value: 'shanghai' },
        { label: '广州', value: 'guangzhou' },
        { label: '深圳（暂不可选）', value: 'shenzhen', disabled: true },
      ]
    : [
        { label: 'Beijing', value: 'beijing' },
        { label: 'Shanghai', value: 'shanghai' },
        { label: 'Guangzhou', value: 'guangzhou' },
        { label: 'Shenzhen (unavailable)', value: 'shenzhen', disabled: true },
      ],
);
</script>

<template>
  <div class="demo-column">
    <Select
      v-model:value="value"
      :options="options"
      :placeholder="isZh() ? '请选择城市' : 'Select a city'"
      clearable
    />
    <p class="demo-text">
      {{ isZh() ? '当前选中' : 'Selected' }}：{{ value || (isZh() ? '（未选择）' : '(none)') }}
    </p>
  </div>
</template>

默认值与禁用 ​

defaultValue 指定初始选中；disabled 禁用整个选择器。

Vue
<script setup lang="ts">
import { computed } from 'vue';
import { Select } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const options = computed(() =>
  isZh()
    ? [
        { label: '选项一', value: '1' },
        { label: '选项二', value: '2' },
      ]
    : [
        { label: 'Option 1', value: '1' },
        { label: 'Option 2', value: '2' },
      ],
);
</script>

<template>
  <div class="demo-column">
    <Select :options="options" default-value="1" />
    <Select :options="options" default-value="1" disabled />
  </div>
</template>

多选 / 可搜索 / 虚拟滚动 ​

multiple 以 tag 展示选中项；searchable 按文案过滤；virtual 渲染 1000 项仅维护可视窗口。

Vue
<script setup lang="ts">
import { ref, computed } from 'vue';
import { Select } from '@xui-design/vue';
import type { SelectOption } from '@xui-design/core';
import { isZh } from '../../../i18n';

const basicOptions = computed<SelectOption[]>(() =>
  isZh()
    ? [
        { label: '北京', value: 'beijing' },
        { label: '上海', value: 'shanghai' },
        { label: '广州', value: 'guangzhou' },
        { label: '深圳', value: 'shenzhen' },
      ]
    : [
        { label: 'Beijing', value: 'beijing' },
        { label: 'Shanghai', value: 'shanghai' },
        { label: 'Guangzhou', value: 'guangzhou' },
        { label: 'Shenzhen', value: 'shenzhen' },
      ],
);

const bigOptions = computed<SelectOption[]>(() =>
  Array.from({ length: 1000 }, (_, i) => ({
    label: isZh() ? `选项 ${i + 1}` : `Option ${i + 1}`,
    value: `opt-${i + 1}`,
  })),
);

const cities = ref<string[]>(['beijing']);
const searched = ref('');
const virtualValue = ref('');
</script>

<template>
  <div class="demo-column">
    <Select
      v-model:value="cities"
      :options="basicOptions"
      multiple
      :placeholder="isZh() ? '多选城市' : 'Multi-select cities'"
    />
    <p class="demo-text">
      {{ isZh() ? '多选已选' : 'Multi-selected' }}：{{
        cities.join(isZh() ? '、' : ', ') || (isZh() ? '（无）' : '(none)')
      }}
    </p>

    <Select
      v-model:value="searched"
      :options="basicOptions"
      searchable
      clearable
      :placeholder="isZh() ? '输入关键字过滤' : 'Type a keyword to filter'"
    />
    <p class="demo-text">
      {{ isZh() ? '可搜索当前选中' : 'Searchable selected' }}：{{
        searched || (isZh() ? '（未选择）' : '(none)')
      }}
    </p>

    <Select
      v-model:value="virtualValue"
      :options="bigOptions"
      virtual
      :max-height="200"
      :placeholder="isZh() ? '虚拟滚动 · 1000 项' : 'Virtual scroll · 1000 items'"
    />
    <p class="demo-text">
      {{ isZh() ? '虚拟滚动当前选中' : 'Virtual scroll selected' }}：{{
        virtualValue || (isZh() ? '（未选择）' : '(none)')
      }}
    </p>
  </div>
</template>

分组选项 ​

options 传入 SelectOptionGroup 结构，分组内选项统一展示，支持分组级 disabled。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Select } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const value = ref('');

const options = [
  {
    label: isZh() ? '一线城市' : 'Tier-1 Cities',
    options: [
      { label: '北京', value: 'beijing' },
      { label: '上海', value: 'shanghai' },
      { label: '广州', value: 'guangzhou' },
      { label: '深圳', value: 'shenzhen' },
    ],
  },
  {
    label: isZh() ? '新一线城市' : 'New Tier-1 Cities',
    options: [
      { label: '杭州', value: 'hangzhou' },
      { label: '成都', value: 'chengdu' },
      { label: '武汉', value: 'wuhan', disabled: true },
    ],
  },
];
</script>

<template>
  <div class="demo-column">
    <Select v-model:value="value" :options="options" clearable />
    <p class="demo-text">
      {{ isZh() ? `选中值：${value || '（未选择）'}` : `Value: ${value || '(none)'}` }}
    </p>
  </div>
</template>

契约类型 ​

SelectOption

ts
interface SelectOption {
  label: string
  value: string
  disabled?: boolean
}

下拉选项配置。

SelectOptionGroup

ts
interface SelectOptionGroup {
  label: string
  options: SelectOption[]
  disabled?: boolean
}

下拉选项分组配置。

SelectSource

ts
type SelectSource = (SelectOption | SelectOptionGroup)[];

options 数据源：支持扁平选项数组或分组混合。

SelectValue

ts
type SelectValue = string | string[];

选中值：单选为 string，多选为 string[]（向后兼容：单选行为与旧版一致）。

注意事项 ​

  • 禁用选项不响应点击与键盘高亮，选中禁用项的操作会被静默忽略。
  • 点击组件外部会收起面板且不改变选中值；多选模式点击选项后面板保持展开。
  • 虚拟模式要求选项行高固定（默认 30px，可用 CSS 变量 --xui-select-item-height 对齐调整）。
  • 多选删除某个 tag 即切换取消该项，触发 onChange 携带最新数组。
  • 自带视口避让：视口下方空间不足时面板自动向上展开（根元素加 is-drop-up），滚动与窗口 resize 时实时重算；overflow: hidden 祖先仍可能裁剪面板。

无障碍 ​

  • 选择器可通过 Tab 聚焦，方向键 / Enter / Esc 完成全部键盘操作；禁用项携带禁用语义。
  • 多选面板携带 aria-multiselectable；搜索框独立 role=searchbox。
