下拉菜单 Dropdown 导航布局 ​

把一组动作收纳到触发元素的下拉菜单里，支持悬停 / 点击两种触发方式、四方位弹出与视口避让。

功能特性 ​

  • trigger 支持悬停（默认，带 100ms 展开 / 150ms 收起防抖）与点击两种方式，收起后回调 select 并携带 key 与完整菜单项
  • menu 数组驱动渲染：disabled 禁用项点击无效、danger 危险项红色文案、divided 分隔线、icon 内置图标
  • placement 控制四方位弹出，空间不足自动翻转、溢出视口自动钳制，滚动与 resize 实时重算
  • 点击菜单外部或按 Esc 仅收起菜单，不触发 select；onVisibleChange 通知展开 / 收起

使用场景 ​

  • 工具栏“更多操作”聚合、用户头像菜单、表格行操作过多需要收纳等场景。

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

基础用法 ​

悬停触发元素展开菜单，点击菜单项后收起并回调 select。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Dropdown, Button } from '@xui-design/vue';
import type { DropdownOption } from '@xui-design/core';
import { isZh } from '../../../i18n';

const menu: DropdownOption[] = [
  { key: 'profile', label: isZh() ? '个人中心' : 'Profile', icon: 'user' },
  { key: 'schedule', label: isZh() ? '我的日程' : 'My Schedule', icon: 'calendar' },
  { key: 'logout', label: isZh() ? '退出登录' : 'Sign out', icon: 'close' },
];

const result = ref(isZh() ? '（等待选择）' : '(pending)');

function handleSelect(key: string) {
  result.value = isZh() ? `已选择：${key}` : `Selected: ${key}`;
}

function handleVisibleChange(open: boolean) {
  if (open) result.value = isZh() ? '菜单已展开' : 'Menu opened';
}
</script>

<template>
  <div class="demo-column">
    <Dropdown :menu="menu" @select="handleSelect" @visible-change="handleVisibleChange">
      <Button>{{ isZh() ? '用户菜单' : 'User Menu' }}</Button>
    </Dropdown>
    <p class="demo-text">{{ result }}</p>
  </div>
</template>

点击触发 / 菜单项变体 / 禁用 ​

trigger 切换为点击，placement 右侧弹出；菜单项演示禁用、分隔线、危险项与图标；disabled 下悬停点击均无效。

Vue
<script setup lang="ts">
import { Dropdown, Button } from '@xui-design/vue';
import type { DropdownOption } from '@xui-design/core';
import { isZh } from '../../../i18n';

const menu: DropdownOption[] = [
  { key: 'rename', label: isZh() ? '重命名' : 'Rename', icon: 'plus' },
  { key: 'share', label: isZh() ? '分享' : 'Share', disabled: true },
  { key: 'archive', label: isZh() ? '归档' : 'Archive', divided: true, icon: 'inbox' },
  { key: 'delete', label: isZh() ? '删除' : 'Delete', danger: true, icon: 'close' },
];

const disabledMenu: DropdownOption[] = [
  { key: 'copy', label: isZh() ? '复制' : 'Copy' },
  { key: 'cut', label: isZh() ? '剪切' : 'Cut' },
];
</script>

<template>
  <div class="demo-row">
    <Dropdown :menu="menu" trigger="click" placement="right">
      <Button>{{ isZh() ? '更多操作（点击）' : 'More Actions (click)' }}</Button>
    </Dropdown>
    <Dropdown :menu="disabledMenu" disabled>
      <Button>{{ isZh() ? '禁用状态' : 'Disabled' }}</Button>
    </Dropdown>
  </div>
</template>

注意事项 ​

  • hover 触发内置 100ms 展开 / 150ms 收起防抖，鼠标划过触发器与菜单之间 8px 间隙不会误收起；click 触发时悬停无效。
  • 菜单为 CSS 包裹定位（同 Tooltip / Popconfirm），需注意父容器 overflow 裁剪；ref 命令式 API 提供 show / hide / toggle。
  • icon 取值为 @xui-design/icons 的图标名（如 user / calendar / close），未知名静默忽略不渲染。

无障碍 ​

  • 菜单容器 role="menu"、菜单项 role="menuitem"，禁用项带 aria-disabled；Esc 可收起菜单。方向键在菜单项间移动暂未支持。
