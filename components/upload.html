文件上传 Upload 表单交互 ​

通过点击选择文件并上传，支持多文件、数量 / 大小限制、图片列表展示与上传前校验。

功能特性 ​

  • 受控 / 非受控双模式，值为 UploadFile[]，Vue 端支持 v-model:value
  • action 上传地址；requestUpload 可覆盖默认 XMLHttpRequest 实现（便于 SSR 或自定义请求）
  • multiple 多选；maxCount 限制文件数；maxSize 限制单文件大小
  • listType 支持 text（默认）与 picture（缩略图列表）
  • beforeUpload 返回 false / reject 时中止上传；accept 限制可选文件类型
  • autoUpload=false 时文件进入「待上传」状态，通过 submit() 或「开始上传」按钮手动触发
  • 上传中可取消（cancel），状态变为 cancelled；列表项支持上移/下移排序
  • 上传中实时显示进度百分比、上传速率（KB/s、MB/s）与预估剩余时间
  • 完整状态机：pending / uploading / done / error / cancelled
  • drag 开启拖拽上传形态：虚线 dropzone 支持拖入文件与点击选择，悬停高亮

使用场景 ​

  • 表单中需要上传附件、图片等文件的场景。

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

基础上传 ​

点击选择文件后自动上传（示例使用模拟 requestUpload），支持多选。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Upload } from '@xui-design/vue';
import type { UploadFile } from '@xui-design/core';
import { isZh } from '../../../i18n';

const fileList = ref<UploadFile[]>([]);

// 文档站无真实后端，用模拟上传：1 秒后完成，进度匀速推进
const mockRequest = (
  file: UploadFile,
  options: { action: string; onProgress: (percent: number) => void },
) =>
  new Promise<{ url: string }>((resolve) => {
    let percent = 0;
    const timer = setInterval(() => {
      percent += 20;
      options.onProgress(Math.min(percent, 100));
      if (percent >= 100) {
        clearInterval(timer);
        resolve({ url: `https://example.com/${file.name}` });
      }
    }, 200);
  });
</script>

<template>
  <div class="demo-column">
    <Upload v-model:value="fileList" action="/upload" :request-upload="mockRequest" multiple />
    <p class="demo-text">
      {{ isZh() ? `文件数：${fileList.length}` : `File count: ${fileList.length}` }}
    </p>
  </div>
</template>

图片列表与上传前校验 ​

listType="picture" 展示缩略图；beforeUpload 仅允许图片；maxCount 限制数量。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Upload } from '@xui-design/vue';
import type { UploadFile } from '@xui-design/core';
import { isZh } from '../../../i18n';

const fileList = ref<UploadFile[]>([]);

const mockRequest = (
  file: UploadFile,
  options: { action: string; onProgress: (percent: number) => void },
) =>
  new Promise<{ url: string }>((resolve) => {
    let percent = 0;
    const timer = setInterval(() => {
      percent += 25;
      options.onProgress(Math.min(percent, 100));
      if (percent >= 100) {
        clearInterval(timer);
        resolve({ url: `https://example.com/${file.name}` });
      }
    }, 200);
  });

// 仅允许图片类型
const beforeUpload = (file: File) => file.type.startsWith('image/');
</script>

<template>
  <div class="demo-column">
    <Upload
      v-model:value="fileList"
      action="/upload"
      :request-upload="mockRequest"
      list-type="picture"
      accept="image/*"
      :max-count="3"
      :before-upload="beforeUpload"
    />
    <p class="demo-text">
      {{
        isZh()
          ? 'listType="picture" 图片列表；accept 限制图片；maxCount=3；beforeUpload 校验类型'
          : 'listType="picture" image list; accept restricts to images; maxCount=3; beforeUpload validates type'
      }}
    </p>
  </div>
</template>

手动上传 / 取消 / 排序 / 速率 ​

autoUpload=false 时文件进入待上传状态，可手动开始上传；上传中可取消、可排序，实时显示速率与剩余时间。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Upload } from '@xui-design/vue';
import type { UploadFile } from '@xui-design/core';

// 模拟上传：50% 概率成功，随机进度
const mockRequest = (
  file: UploadFile,
  options: { onProgress: (p: number) => void; signal?: AbortSignal },
) =>
  new Promise<{ url?: string; response?: unknown }>((resolve, reject) => {
    let percent = 0;
    const timer = setInterval(() => {
      if (options.signal?.aborted) {
        clearInterval(timer);
        reject(new DOMException('Aborted', 'AbortError'));
        return;
      }
      percent += Math.random() * 20 + 5;
      if (percent >= 100) {
        percent = 100;
        clearInterval(timer);
        if (Math.random() > 0.2) {
          resolve({ url: `https://example.com/${file.name}`, response: { ok: true } });
        } else {
          reject(new Error('模拟上传失败'));
        }
      }
      options.onProgress(Math.min(Math.round(percent), 100));
    }, 300);
  });

const value = ref<UploadFile[]>([]);
</script>

<template>
  <div class="demo-column">
    <Upload
      v-model:value="value"
      action="/upload"
      multiple
      :auto-upload="false"
      :request-upload="mockRequest"
    />
    <p class="demo-text">autoUpload=false：选中文件后进入「待上传」状态，点击「开始上传」手动触发。</p>
  </div>
</template>

拖拽上传 ​

drag 开启拖拽形态：虚线 dropzone 支持拖入文件与点击选择，悬停时高亮；accept 与多选约束同样生效。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Upload } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const requestUpload = (file: { name: string }) =>
  new Promise<{ url: string }>((resolve) => {
    setTimeout(() => resolve({ url: `/mock/${encodeURIComponent(file.name)}` }), 600);
  });

const doneCount = ref(0);

function handleChange() {
  doneCount.value += 1;
}
</script>

<template>
  <div class="demo-column">
    <Upload
      action="/upload"
      :request-upload="requestUpload"
      drag
      multiple
      accept="image/*,.pdf"
      @change="handleChange"
    />
    <p class="demo-text">
      {{
        isZh()
          ? `已完成上传：${doneCount} 个文件（accept 限定图片与 PDF）`
          : `Uploaded: ${doneCount} (images and PDF only)`
      }}
    </p>
  </div>
</template>

契约类型 ​

UploadFile

ts
interface UploadFile {
  uid: string
  name: string
  size: number
  type: string
  status: 'pending' | 'uploading' | 'done' | 'error' | 'cancelled'
  percent: number
  speed?: number
  remainingTime?: number
  response?: unknown
  url?: string
  raw?: File
}

上传文件项数据结构；speed 为上传速率（字节/秒），remainingTime 为预估剩余时间（秒）。

RequestUploadFn

ts
type RequestUploadFn = (
  file: UploadFile,
  options: { action: string; onProgress: (percent: number) => void; signal?: AbortSignal }
) => Promise<{ url?: string; response?: unknown }>

自定义上传请求函数签名；signal 用于支持取消上传。

注意事项 ​

  • 默认使用 XMLHttpRequest 上传；SSR 或非浏览器环境需通过 requestUpload 提供实现。
  • beforeUpload 返回 false 或 reject 的 Promise 时，文件不会进入上传流程。
  • maxCount 限制文件总数（含已上传），超出部分直接忽略；maxSize 超限的文件标记为 error 不上传。
  • autoUpload=false 时，文件进入 pending 状态，需调用 submit() 或点击「开始上传」触发；cancelled 状态的文件需删除后重新选择。

无障碍 ​

  • 上传触发区域为可聚焦的原生按钮，禁用状态透传 disabled。
