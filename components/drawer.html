抽屉 Drawer 基础组件 ​

从屏幕边缘滑出的抽屉面板，承载表单、详情等次级内容；支持四个方向、自定义尺寸、焦点陷阱 / 焦点恢复与 ref 命令式控制。

功能特性 ​

  • 受控 visible / 非受控 defaultVisible，Vue 端支持 v-model:visible
  • placement 四个滑入方向：left / right / top / bottom（默认 right）
  • size 自定义尺寸：左右方向为宽度，上下方向为高度（数字按 px，字符串原样输出，默认 378）
  • mask 可关闭遮罩；maskClosable 遮罩点击关闭、closeOnEsc ESC 关闭
  • 焦点陷阱：打开期间 Tab 循环约束在抽屉内（trapFocus 可关闭）；关闭后焦点恢复到打开前元素
  • default / title / footer / closeIcon 插槽（React 对应 children / renderTitle / renderFooter / renderCloseIcon）
  • 通过 ref 暴露 open() / close() / toggle() 命令式方法（类型 DrawerRef）

使用场景 ​

  • 表单编辑、详情查看、筛选面板等不打断主流程但需要较大展示面积的场景。

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

受控抽屉 ​

外部维护 visible 状态，footer 插槽自定义底部按钮。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Button, Drawer } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const visible = ref(false);
</script>

<template>
  <div class="demo-column">
    <Button type="primary" @click="visible = true">{{
      isZh() ? '打开抽屉' : 'Open drawer'
    }}</Button>
    <Drawer
      v-model:visible="visible"
      :title="isZh() ? '编辑资料' : 'Edit profile'"
      @close="visible = false"
    >
      <p>
        {{
          isZh()
            ? '这是一段抽屉内容，可承载表单或详情信息。'
            : 'Drawer body text. Use it for forms or detail information.'
        }}
      </p>
      <template #footer>
        <Button @click="visible = false">{{ isZh() ? '取消' : 'Cancel' }}</Button>
        <Button type="primary" @click="visible = false">{{ isZh() ? '确认' : 'Confirm' }}</Button>
      </template>
    </Drawer>
  </div>
</template>

四个方向 ​

placement 控制抽屉从左 / 右 / 上 / 下哪个边缘滑入。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Button, Drawer } from '@xui-design/vue';
import type { DrawerPlacement } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const visible = ref(false);
const placement = ref<DrawerPlacement>('right');

const open = (next: DrawerPlacement) => {
  placement.value = next;
  visible.value = true;
};
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button @click="open('left')">{{ isZh() ? '左侧' : 'Left' }}</Button>
      <Button @click="open('right')">{{ isZh() ? '右侧' : 'Right' }}</Button>
      <Button @click="open('top')">{{ isZh() ? '顶部' : 'Top' }}</Button>
      <Button @click="open('bottom')">{{ isZh() ? '底部' : 'Bottom' }}</Button>
    </div>
    <Drawer
      v-model:visible="visible"
      :placement="placement"
      :title="isZh() ? '四方向抽屉' : 'Placements'"
      :size="placement === 'top' || placement === 'bottom' ? 240 : 320"
    >
      <p>
        {{
          isZh()
            ? 'placement 控制抽屉滑入方向：left / right / top / bottom。'
            : 'placement controls the slide-in edge: left / right / top / bottom.'
        }}
      </p>
    </Drawer>
  </div>
</template>

ref 命令式控制 ​

无需维护 visible，直接调用实例 open() / close() / toggle()。

Vue
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { Button, Drawer } from '@xui-design/vue';
import type { DrawerRef } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const drawerRef = useTemplateRef<DrawerRef>('drawer');
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button type="primary" @click="drawerRef?.open()">{{
        isZh() ? 'ref 打开' : 'Open via ref'
      }}</Button>
      <Button @click="drawerRef?.toggle()">{{ isZh() ? '切换' : 'Toggle' }}</Button>
    </div>
    <Drawer ref="drawer" :title="isZh() ? '命令式抽屉' : 'Imperative drawer'">
      <p>
        {{
          isZh()
            ? '无需维护 visible，直接调用实例 open() / close() / toggle()。'
            : 'No need to maintain visible; call open() / close() / toggle() on the instance.'
        }}
      </p>
      <template #footer>
        <Button type="primary" @click="drawerRef?.close()">{{ isZh() ? '关闭' : 'Close' }}</Button>
      </template>
    </Drawer>
  </div>
</template>

注意事项 ​

  • footer 无默认按钮（与 Modal 不同），底部操作区完全由 footer 插槽接管。
  • ref 实例类型为 DrawerRef，提供 open() / close() / toggle() 三个方法。
  • size 作用于交叉轴：left/right 方向设置 width，top/bottom 方向设置 height。

无障碍 ​

  • 面板携带 role="dialog"（mask 开启时附加 aria-modal="true"）；打开时聚焦面板，Tab / Shift+Tab 循环约束在抽屉内。
  • 关闭后焦点恢复到打开前的元素，键盘用户不会丢失位置；支持 ESC 关闭（closeOnEsc）。
