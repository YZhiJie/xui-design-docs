进度条 Progress 数据展示 ​

展示任务进度百分比，支持线性与环形两种形态及成功 / 失败状态色。

功能特性 ​

  • type 支持 'line' 线性与 'circle' 环形（SVG 描边）
  • percent 自动收敛到 [0, 100]，非数值按 0 处理
  • status 支持 normal / success / error；percent 达到 100 且未显式指定时自动派生 success
  • strokeWidth 自定义条粗 / 描边宽度，showText 控制百分比文本

使用场景 ​

  • 文件上传 / 下载、任务处理进度、加载完成度展示等场景。

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

线性与环形 ​

同一百分比驱动 line 与 circle 两种形态，按钮模拟进度变化。

Vue
<script setup lang="ts">
import { computed, ref } from 'vue';
import { Button, Progress } from '@xui-design/vue';

const percent = ref(35);
const add = (delta: number) => {
  percent.value = Math.min(100, Math.max(0, percent.value + delta));
};
const circlePercent = computed(() => percent.value);
</script>

<template>
  <div class="demo-column">
    <Progress :percent="percent" />
    <Progress type="circle" :percent="circlePercent" :stroke-width="8" />
    <div class="demo-row">
      <Button size="sm" @click="add(-10)">-10%</Button>
      <Button size="sm" type="primary" @click="add(10)">+10%</Button>
    </div>
  </div>
</template>

成功与失败状态 ​

100% 默认派生 success；显式 status="error" 显示失败色。

Vue
<script setup lang="ts">
import { Progress } from '@xui-design/vue';
</script>

<template>
  <div class="demo-column">
    <Progress :percent="100" />
    <Progress :percent="100" status="error" />
    <Progress :percent="60" />
  </div>
</template>

契约类型 ​

ProgressStatus

ts
type ProgressType = 'line' | 'circle'
type ProgressStatus = 'normal' | 'success' | 'error'

进度条形态与状态枚举。

注意事项 ​

  • 纯展示组件，无事件；达到 100% 时若未显式传入 status，颜色自动切换为成功色。

无障碍 ​

  • 进度根节点携带进度百分比语义（role="progressbar" 及 aria-valuenow / min / max）。
