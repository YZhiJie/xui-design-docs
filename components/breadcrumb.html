面包屑 Breadcrumb 导航布局 ​

显示当前页面层级路径，支持链接项 / 可点击项与自定义分隔符。

功能特性 ​

  • items 配置层级，最后一项自动视为当前页（不可点击）
  • item 存在 href 时渲染为 <a>，否则渲染为可点击 <span>；separator 自定义分隔符（默认 '/'）
  • disabled 项与末项不触发 itemClick

使用场景 ​

  • 详情页层级返回、管理系统内容分区定位等场景。

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

基础与分隔符 ​

末项为当前页；separator 可替换默认斜杠。

Vue
<script setup lang="ts">
import { computed } from 'vue';
import { Breadcrumb } from '@xui-design/vue';
import type { BreadcrumbItem } from '@xui-design/core';
import { isZh } from '../../../i18n';

const items = computed<BreadcrumbItem[]>(() =>
  isZh()
    ? [{ label: '首页' }, { label: '组件库' }, { label: '面包屑 Breadcrumb' }]
    : [{ label: 'Home' }, { label: 'Components' }, { label: 'Breadcrumb' }],
);
</script>

<template>
  <div class="demo-column">
    <Breadcrumb :items="items" />
    <Breadcrumb :items="items" separator=">" />
  </div>
</template>

点击与禁用 ​

无 href 的项点击触发 itemClick；disabled 项与末项被忽略。

Vue
<script setup lang="ts">
import { computed, ref } from 'vue';
import { Breadcrumb } from '@xui-design/vue';
import type { BreadcrumbItem } from '@xui-design/core';
import { isZh } from '../../../i18n';

const lastClick = ref(isZh() ? '（点击前级项试试）' : '(Try clicking a non-last item)');
const items = computed<BreadcrumbItem[]>(() =>
  isZh()
    ? [{ label: '首页' }, { label: '归档（禁用）', disabled: true }, { label: '文章详情' }]
    : [
        { label: 'Home' },
        { label: 'Archive (disabled)', disabled: true },
        { label: 'Article Detail' },
      ],
);

const onItemClick = (item: BreadcrumbItem, index: number) => {
  lastClick.value = isZh()
    ? `点击了第 ${index} 项：${item.label}`
    : `Clicked item ${index}: ${item.label}`;
};
</script>

<template>
  <div class="demo-column">
    <Breadcrumb :items="items" @item-click="onItemClick" />
    <p class="demo-text">
      {{ lastClick
      }}{{
        isZh() ? '（末项为当前页，不可点击）' : ' (last item is the current page, not clickable)'
      }}
    </p>
  </div>
</template>

契约类型 ​

BreadcrumbItem

ts
interface BreadcrumbItem {
  label: string
  href?: string
  disabled?: boolean
}

面包屑层级项；href 存在渲染为链接。

注意事项 ​

  • 组件本身不拦截链接默认导航（对齐 Element Plus），SPA 内路由拦截由应用层负责。
  • 在 hash 路由应用中若不希望改变地址，可省略 href，改用 itemClick 处理跳转。

无障碍 ​

  • 根节点使用 nav + aria-label="面包屑"，当前页以 aria-current 标识。
