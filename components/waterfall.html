瀑布流 Waterfall 数据展示 ​

基于最短列贪心分配的多列瀑布流布局：支持响应式断点自适应列数、图片/内容加载后自动触发重排、高度缓存避免重复测量，列数切换时零成本复用已测量高度。

功能特性 ​

  • 最短列贪心分配 + 并列 round-robin，初始未测量场景均匀分布
  • 响应式断点（breakpoints）自动跟随容器尺寸变化切换列数
  • 高度缓存跨列数切换复用：切换 4→2 列时不重新测量 DOM
  • 图片 / 内容异步加载完成后 ResizeObserver 自动触发重排
  • rAF 合并调度：一帧内多次变化只执行一次重排，避免抖动
  • CSS 变量 gutter 可覆盖间距（--xui-waterfall-gutter）

使用场景 ​

  • 图片画廊 / 商品卡片列表（高度不一的混合内容）
  • 搜索结果页：按最短列自动对齐，视觉紧凑
  • 自适应仪表盘：窗口缩放 → 自动调整列数

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

基础用法 ​

固定 3 列、间距 16px，传入不等高数据演示最短列贪心分配；点击触发 itemClick 事件。

Vue

  { id: 6, title: '卡片 F', height: 140 },
  { id: 7, title: '卡片 G', height: 280 },

响应式断点 ​

配置 breakpoints 后，容器宽度变化时自动切换列数（<600px 1 列 / 600-1000px 2 列 / >1000px 3 列），高度缓存复用零成本。

Vue

  id: i,
  title: `卡片 ${i + 1}`,
  height: 80 + Math.floor(Math.random() * 200),
}));

const breakpoints = [
  { minWidth: 0, columns: 1 },
  { minWidth: 600, columns: 2 },
  { minWidth: 1000, columns: 3 },
];
</script>

<template>

服务端加载 + 无限滚动 ​

模拟分页接口（setTimeout + picsum.photos 随机图），滚动触底触发 loadMore 拉取下一页；图片 onLoad 后 ResizeObserver 自动重排；配合 loading / finished 守卫避免重复触发。

Vue
<script setup lang="ts">
import { onMounted, ref } from 'vue';
import { Waterfall } from '@xui-design/vue';

type ImageItem = {
  id: number;
  url: string;
  width: number;
  height: number;
  title: string;
};

const PAGE_SIZE = 10;
const MAX_PAGES = 4;
let pageCounter = 0;

/** 模拟从服务端拉取一页图片 */
function mockFetchImages(page: number): Promise<ImageItem[]> {
  return new Promise((resolve) => {
    setTimeout(() => {
      const items: ImageItem[] = Array.from({ length: PAGE_SIZE }, (_, i) => {
        const w = 400;
        const h = 200 + Math.floor(Math.random() * 300); // 随机高度，产生瀑布流错落
        const seed = page * PAGE_SIZE + i + 1;
        return {
          id: seed,
          // picsum.photos 支持 seed，保证同一张图在多次渲染时稳定显示
          url: `https://picsum.photos/seed/waterfall-${seed}/${w}/${h}`,
          width: w,
          height: h,
          title: `图片 ${seed}`,
        };
      });
      resolve(items);
    }, 700); // 模拟网络耗时
  });
}

const items = ref<ImageItem[]>([]);
const loading = ref(false);
const finished = ref(false);
// 按图片 id 记录加载状态，用于控制骨架屏 / 图片淡入
const loadedIds = ref<Set<number>>(new Set());

function onImageLoaded(id: number) {
  loadedIds.value = new Set(loadedIds.value).add(id);
}

async function loadMore() {
  if (loading.value || finished.value) return;
  loading.value = true;
  try {
    pageCounter += 1;
    const newItems = await mockFetchImages(pageCounter);
    items.value = [...items.value, ...newItems];
    if (pageCounter >= MAX_PAGES) finished.value = true;
  } finally {
    loading.value = false;
  }
}

onMounted(() => {
  loadMore();
});
</script>

<template>
  <div class="server-demo">
    <p class="tip">
      💡 滚动容器触底会触发 loadMore，从"服务端"拉取下一批图片；图片加载完成后瀑布流自动重排
    </p>

    <Waterfall
      :items="items"
      row-key="id"
      :columns="3"
      :gutter="12"
      :height="420"
      :loading="loading"
      :finished="finished"
      @load-more="loadMore"
    >
      <template #item="{ item }">
        <div v-if="item" class="img-card">
          <!-- 用 aspect-ratio 按图片真实宽高占位，避免加载前布局跳动 -->
          <div
            class="img-card__media"
            :style="{ aspectRatio: `${(item as ImageItem).width} / ${(item as ImageItem).height}` }"
          >
            <!-- 加载前的 shimmer 占位 -->
            <div v-if="!loadedIds.has((item as ImageItem).id)" class="img-card__skeleton" />
            <img
              :src="(item as ImageItem).url"
              :alt="(item as ImageItem).title"
              loading="lazy"
              class="img-card__image"
              :class="{ 'is-loaded': loadedIds.has((item as ImageItem).id) }"
              @load="onImageLoaded((item as ImageItem).id)"
            />
          </div>
          <div class="img-card__caption">
            <span>{{ (item as ImageItem).title }}</span>
            <span class="img-card__size">
              {{ (item as ImageItem).width }}×{{ (item as ImageItem).height }}
            </span>
          </div>
        </div>
      </template>

      <template #empty>
        <div class="empty-state">加载中...</div>
      </template>
    </Waterfall>

    <div class="footer-state" v-if="finished">已加载全部 {{ MAX_PAGES * PAGE_SIZE }} 张图片</div>
    <div class="footer-state loading-indicator" v-else-if="loading">
      <span class="spinner" /> 加载中...
    </div>
  </div>
</template>

布局变更载荷

注意事项 ​

  • 高度缓存（Map<key, number>）在逻辑层维护，列数变化时直接复用，零 DOM 测量开销。
  • ResizeObserver 全局监听 item 高度变化，图片 onLoad 后自动触发 updateItemHeight → 重排。
  • jsdom / 旧环境无 ResizeObserver 时降级为首次同步测量，核心布局逻辑不受影响。
  • renderItem 未提供时渲染 xui-waterfall__item-placeholder 占位，业务方应通过 renderItem / #item slot 填充实际内容。

无障碍 ​

  • 根节点为语义化容器，条目点击时使用原生 div onClick；若需按钮可访问性建议在 slot 内容里自行封装 button 元素。
