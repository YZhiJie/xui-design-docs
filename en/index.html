XUICross-Framework UI

One core contract, isomorphic components for Vue 3 and React 19

Components
Theming

Single Contract @xui-design/core

ComponentSpec is the only contract for both frameworks. Props / Events / Slots are defined at the contract layer; adapters must not diverge.

Isomorphic Vue / React

Same components, same API surface: Vue events map to React callbacks, Vue slots map to React renderXxx props one by one.

Single Source of Styles

@xui-design/styles ships unified BEM class names and CSS variable theming — zero style drift across frameworks.

Single Core Logic Implementation

@xui-design/shared holds state and interaction logic; both adapters stay thin. Fully typed under TypeScript strict mode.

Installation

Shell
pnpm add @xui-design/vue @xui-design/styles

# Install the types package if you need contract types (e.g. TableColumn)
pnpm add @xui-design/core

# Import styles once in your app entry
# main.ts:  import '@xui-design/styles'

Quick Start

Vue
<script setup lang="ts">
import { Button } from '@xui-design/vue';
import '@xui-design/styles';
</script>

<template>
  <Button type="primary">Hello XUI</Button>
</template>

Components Overview

Basic

Button 按钮

A basic button component with multiple semantic types, sizes, loading and disabled states.

Input 输入框

A basic text input with controlled / uncontrolled modes, a clear button, prefix / suffix, and multiple native types.

Modal 对话框

A modal dialog for information or actions that require explicit handling, with focus trap / focus restore, customizable footer text, and both controlled and ref-based imperative usage.

Form

Switch 开关

A boolean toggle switch with controlled / uncontrolled modes and a loading state.

Checkbox 复选框

Select multiple options from a set, or use standalone as a two-state toggle, with indeterminate state support.

Radio 单选框

Select one option from a mutually exclusive set. RadioGroup manages the selected value with Radio as the child item; an options array is also supported.

Select 下拉选择

Pick values from a pop-up option panel, with single / multiple selection, search, and virtual scrolling, plus full keyboard support and ARIA semantics.

DatePicker 日期选择

Click to open a month calendar and pick a single date; the value is always a YYYY-MM-DD string, with zero date dependencies.

InputNumber 数字输入框

Enter numbers via stepper buttons or direct typing, with automatic range clamping, step alignment, and precision handling.

Form 表单

A full-featured form container with field registration, sync/async validation, cross-field rules, conditional validation, dynamic add/remove fields, and disabled/readonly/label layout support.

Data Display

Tag 标签

A small tag for labeling and categorization, with five semantic types, two sizes, and closable interaction.

Progress 进度条

Displays task progress as a percentage, in linear or circular form, with success / error status colors.

Badge 徽标数

Shows a message count or status dot as a corner badge; can wrap any content or be used standalone.

Avatar 头像

Displays an image or text avatar for a user or entity, with three sizes, circle / square shapes, and image-failure fallback.

Empty 空状态

Placeholder for empty data or no results, with a built-in default illustration and customizable description, illustration, and action area.

Skeleton 骨架屏

Placeholder screen shown while data is loading, conveying structure before content is ready, with avatar placeholder and customizable row count.

Table 表格

A structured data table with column definitions, uncontrolled sorting, row selection, virtual scrolling, custom cells, and an empty state.

Navigation

Tabs 标签页

Switches between multiple peer content panels in the same area, with configurable tab items, controlled / uncontrolled modes, and keyboard navigation.

Pagination 分页

Data pagination navigation with 1-based page numbers, automatically computing the total page count and clamping out-of-range operations.

Breadcrumb 面包屑

Shows the hierarchical path of the current page, supporting link items / clickable items and a custom separator.

Feedback

Alert 警告提示

A static inline banner for information that needs user attention, with four semantic types, icon and closable support.

Message 全局提示

Imperative global toast with an isomorphic API across frameworks; the container mounts automatically on first call, no host component needed.

Tooltip 文字提示

A simple text bubble shown on hover or focus, positioned with a CSS wrapper (no portal), supporting four placements and two triggers.

Spin 加载中

A loading indicator that works standalone or wraps content with a mask to indicate block-level loading.

Popconfirm 气泡确认

A lightweight confirmation bubble triggered by clicking an element, ideal for actions like "delete" that need a second confirmation without interrupting the whole page.
