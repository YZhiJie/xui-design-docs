TimeSlotPicker 投放时段 Form ​

Heatmap-style time slot selector supporting day/week/month/year granularities with click toggle and rectangular drag selection.

Features ​

  • Four granularities: day (hours), week (week × hours), month (calendar), year (full-year heatmap)
  • Two selection modes: click to toggle single, or drag to select/deselect a rectangular region (anchor and current cell form the rectangle, committed on mouseup)
  • Controlled and uncontrolled modes; supports v-model for Vue and value + onChange for React
  • referenceDate determines the month/year view, defaults to the current date
  • Optional footer with stats and legend showing selected/total slots
  • Imperative API for external control: clear / selectAll / toggle

When to Use ​

  • Ad delivery scheduling, appointment time selection, shift scheduling
  • Checkbox selection on heatmap-style date/time grids

Examples ​

Each demo can be switched between Vue and React tabs for live interaction, with source code available per framework.

Basic Usage ​

Switch between four granularities. Click to toggle a slot, or drag a rectangle to select/deselect a region. Two-way binding with v-model.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { TimeSlotPicker, Button } from '@xui-design/vue';
import type { TimeSlotGranularity } from '@xui-design/core';
import { isZh } from '../../../i18n';

const granularity = ref<TimeSlotGranularity>('week');
const value = ref<string[]>(['w:1:09', 'w:1:10', 'w:2:14', 'w:3:19']);

const options: { key: TimeSlotGranularity; zh: string; en: string }[] = [
  { key: 'day', zh: '按日', en: 'Day' },
  { key: 'week', zh: '按周', en: 'Week' },
  { key: 'month', zh: '按月', en: 'Month' },
  { key: 'year', zh: '按年', en: 'Year' },
];

const switchGranularity = (key: TimeSlotGranularity) => {
  if (granularity.value === key) return;
  granularity.value = key;
  value.value = [];
};
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button
        v-for="option in options"
        :key="option.key"
        size="sm"
        :type="granularity === option.key ? 'primary' : 'default'"
        @click="switchGranularity(option.key)"
      >
        {{ isZh() ? option.zh : option.en }}
      </Button>
    </div>
    <TimeSlotPicker v-model:value="value" :granularity="granularity" reference-date="2026-10-20" />
    <span class="demo-text">
      {{ isZh() ? `已选择 ${value.length} 个时段` : `${value.length} slots selected` }}
    </span>
  </div>
</template>

Imperative API ​

Call selectAll to select the entire current month and clear to unselect all via ref.

Vue
<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import { TimeSlotPicker, Button } from '@xui-design/vue';
import type { TimeSlotPickerRef } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const pickerRef = useTemplateRef<TimeSlotPickerRef>('picker');
const value = ref<string[]>(['2026-10-01', '2026-10-02']);
</script>

<template>
  <div class="demo-column">
    <TimeSlotPicker
      ref="picker"
      v-model:value="value"
      granularity="month"
      reference-date="2026-10-20"
    />
    <div class="demo-row">
      <Button size="sm" @click="pickerRef?.selectAll()">
        {{ isZh() ? '全选本月' : 'Select month' }}
      </Button>
      <Button size="sm" @click="pickerRef?.clear()">
        {{ isZh() ? '清空' : 'Clear' }}
      </Button>
      <span class="demo-text">
        {{ isZh() ? `已选择 ${value.length} 天` : `${value.length} days selected` }}
      </span>
    </div>
  </div>
</template>

Rectangular Selection ​

In the month view, hold and drag: the anchor and current cell form a translucent preview rectangle, committed on mouseup. Dragging from a selected cell deselects the rectangle.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { TimeSlotPicker } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const value = ref<string[]>(['2026-10-06', '2026-10-07', '2026-10-13', '2026-10-14']);
</script>

<template>
  <div class="demo-column">
    <TimeSlotPicker v-model:value="value" granularity="month" reference-date="2026-10-20" />
    <span class="demo-text">
      {{
        isZh()
          ? '按住鼠标左键拖拽：锚点与当前格子围成矩形，半透明预览，松开后一次性提交；从已选格子开始拖拽则批量取消。'
          : 'Hold and drag: the anchor and current cell form a rectangle (translucent preview), committed on release. Dragging from a selected cell deselects the rectangle.'
      }}
    </span>
  </div>
</template>

Uncontrolled Usage ​

Set the initial value with defaultValue; the component owns the state and emits change / onChange. showFooter=false hides the footer stats.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { TimeSlotPicker } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const latest = ref<string[]>([]);
</script>

<template>
  <div class="demo-column">
    <TimeSlotPicker
      :default-value="['h:09', 'h:10', 'h:18']"
      granularity="day"
      :show-footer="false"
      @change="latest = $event"
    />
    <span class="demo-text">
      {{ isZh() ? 'onChange：' : 'onChange: ' }}{{ latest.length ? latest.join(', ') : '—' }}
    </span>
  </div>
</template>

Disabled & Custom Style ​

disabled blocks all interactions. Pass component-level CSS variables via style to adjust cell size, gap and theme color for this instance only.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Button, TimeSlotPicker } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const disabled = ref(true);
const value = ref<string[]>(['w:3:10', 'w:3:11', 'w:4:15']);

// 组件级 CSS 变量：仅作用于当前实例
const pickerStyle = {
  '--xui-time-slot-size': '28px',
  '--xui-time-slot-gap': '5px',
  '--xui-color-primary': '#0ea5e9',
};
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button size="sm" @click="disabled = !disabled">
        {{ disabled ? (isZh() ? '启用' : 'Enable') : isZh() ? '禁用' : 'Disable' }}
      </Button>
    </div>
    <TimeSlotPicker
      v-model:value="value"
      granularity="week"
      :disabled="disabled"
      :style="pickerStyle"
    />
  </div>
</template>

Imperative Methods ​

Imperative Methods

MethodSignatureDescription

Notes ​

  • Key format: day → h:HH; week → w:W:HH; month/year → YYYY-MM-DD (weekday 1-7, 1 = Monday).
  • Rectangular selection: the pressed cell is the anchor and, together with the hovered cell, defines a rectangle. Cells preview translucently while dragging and commit on mouseup. An unselected anchor selects the whole rectangle; a selected anchor deselects it.
  • Year view uses a column layout starting on Monday (first row Monday, last row Sunday). The column headers mark the column containing the first day of each month.

Accessibility ​

  • Root uses role=group with an aria-label; each cell is a button with aria-pressed indicating selected state; keyboard focus navigation supported.
