Badge 徽标数 Data Display ​

Shows a message count or status dot as a corner badge; can wrap any content or be used standalone.

Features ​

  • Wrapper mode: the badge floats at the top-right corner of the content; renders standalone without children
  • Shows ${max}+ when count exceeds max (max defaults to 99)
  • dot renders a dot badge ignoring the numeric value; showZero controls whether a count of 0 is shown

When to Use ​

  • Unread message / notification counts, status dots for new content, and more.

Examples ​

Each demo can be switched between Vue and React tabs for live interaction, with source code available per framework.

Count & Max ​

count changes dynamically and collapses to 99+ once it exceeds max.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Badge, Button } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const count = ref(5);
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Badge :count="count">
        <Button>{{ isZh() ? '消息' : 'Messages' }}</Button>
      </Badge>
      <Badge :count="120" :max="99">
        <Button>{{ isZh() ? '通知' : 'Notifications' }}</Button>
      </Badge>
    </div>
    <div class="demo-row">
      <Button size="sm" @click="count = Math.max(0, count - 1)">-1</Button>
      <Button size="sm" type="primary" @click="count++">
        {{ isZh() ? '+1（试试超过 99）' : '+1 (try over 99)' }}
      </Button>
    </div>
  </div>
</template>

Dot / Zero / Standalone ​

dot only hints that there are updates; showZero decides whether 0 is shown; renders standalone without wrapped content.

Vue
<script setup lang="ts">
import { Badge } from '@xui-design/vue';
import { isZh } from '../../../i18n';
</script>

<template>
  <div class="demo-row">
    <Badge dot>
      <span class="demo-anchor">{{ isZh() ? '小红点' : 'Dot' }}</span>
    </Badge>
    <Badge :count="0" show-zero>
      <span class="demo-anchor">showZero</span>
    </Badge>
    <Badge :count="0">
      <span class="demo-anchor">{{ isZh() ? '零值隐藏' : 'Hidden when zero' }}</span>
    </Badge>
    <Badge :count="8" />
  </div>
</template>

<style scoped>
.demo-anchor {
  padding: 6px 12px;
  background: #f1f5f9;
  border-radius: 6px;
}
</style>

API ​

@xui-design/core ComponentSpec · single contract, identical on both frameworks

Props ​

Props

PropTypeDefaultDescription
countnumber—Badge count (hidden when not provided; only serves as accessibility semantics in dot mode)
maxnumber99Maximum value (shows `${max}+` when exceeded)
dotbooleanfalseDot badge (ignores count and max)
showZerobooleanfalseWhether to show the badge when count is 0 (hidden by default)
classNamestring—Custom class name appended to the root element
styleRecord<string, string>—Custom styles appended to the root element

Slots / Render Callbacks ​

Slots / Render Callbacks

Slot (Vue)Callback (React)Description
defaultchildrenContent wrapped by the badge (the badge renders standalone when not provided)

Notes ​

  • A purely presentational component with no events; the badge takes up no space when count is 0 and showZero is off.

Accessibility ​

  • Numeric badges expose the count as readable text; dot mode acts as a status hint, and decorative content is hidden from screen readers.
