Upload 文件上传 Form ​

Select and upload files by clicking; supports multiple files, count / size limits, picture list display, and pre-upload validation.

Features ​

  • Controlled and uncontrolled modes; the value is UploadFile[]; supports v-model:value on Vue
  • action is the upload URL; requestUpload can override the default XMLHttpRequest (useful for SSR or custom requests)
  • multiple for multi-file; maxCount limits the file count; maxSize limits each file size
  • listType supports text (default) and picture (thumbnail list)
  • beforeUpload returning false / a rejected promise aborts the upload; accept restricts selectable file types
  • When autoUpload=false, files enter a "pending" state and are uploaded manually via submit() or the "Start Upload" button
  • In-progress uploads can be cancelled (status becomes cancelled); list items support move up / down ordering
  • Displays real-time progress percentage, upload speed (KB/s, MB/s), and estimated remaining time during upload
  • Full state machine: pending / uploading / done / error / cancelled
  • drag enables the drag-and-drop style: a dashed dropzone accepting dropped files and clicks, highlighted on hover

When to Use ​

  • Form scenarios requiring file uploads such as attachments and images.

Examples ​

Each demo can be switched between Vue and React tabs for live interaction, with source code available per framework.

Basic Upload ​

Files upload automatically after selection (the demo uses a mocked requestUpload); multiple selection supported.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Upload } from '@xui-design/vue';
import type { UploadFile } from '@xui-design/core';
import { isZh } from '../../../i18n';

const fileList = ref<UploadFile[]>([]);

// 文档站无真实后端，用模拟上传：1 秒后完成，进度匀速推进
const mockRequest = (
  file: UploadFile,
  options: { action: string; onProgress: (percent: number) => void },
) =>
  new Promise<{ url: string }>((resolve) => {
    let percent = 0;
    const timer = setInterval(() => {
      percent += 20;
      options.onProgress(Math.min(percent, 100));
      if (percent >= 100) {
        clearInterval(timer);
        resolve({ url: `https://example.com/${file.name}` });
      }
    }, 200);
  });
</script>

<template>
  <div class="demo-column">
    <Upload v-model:value="fileList" action="/upload" :request-upload="mockRequest" multiple />
    <p class="demo-text">
      {{ isZh() ? `文件数：${fileList.length}` : `File count: ${fileList.length}` }}
    </p>
  </div>
</template>

Picture List & Pre-upload Validation ​

listType="picture" shows thumbnails; beforeUpload allows only images; maxCount limits the count.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Upload } from '@xui-design/vue';
import type { UploadFile } from '@xui-design/core';
import { isZh } from '../../../i18n';

const fileList = ref<UploadFile[]>([]);

const mockRequest = (
  file: UploadFile,
  options: { action: string; onProgress: (percent: number) => void },
) =>
  new Promise<{ url: string }>((resolve) => {
    let percent = 0;
    const timer = setInterval(() => {
      percent += 25;
      options.onProgress(Math.min(percent, 100));
      if (percent >= 100) {
        clearInterval(timer);
        resolve({ url: `https://example.com/${file.name}` });
      }
    }, 200);
  });

// 仅允许图片类型
const beforeUpload = (file: File) => file.type.startsWith('image/');
</script>

<template>
  <div class="demo-column">
    <Upload
      v-model:value="fileList"
      action="/upload"
      :request-upload="mockRequest"
      list-type="picture"
      accept="image/*"
      :max-count="3"
      :before-upload="beforeUpload"
    />
    <p class="demo-text">
      {{
        isZh()
          ? 'listType="picture" 图片列表；accept 限制图片；maxCount=3；beforeUpload 校验类型'
          : 'listType="picture" image list; accept restricts to images; maxCount=3; beforeUpload validates type'
      }}
    </p>
  </div>
</template>

Manual Upload / Cancel / Order / Speed ​

With autoUpload=false files stay pending until manually started; in-progress uploads can be cancelled and reordered, with real-time speed and remaining time displayed.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Upload } from '@xui-design/vue';
import type { UploadFile } from '@xui-design/core';

// 模拟上传：50% 概率成功，随机进度
const mockRequest = (
  file: UploadFile,
  options: { onProgress: (p: number) => void; signal?: AbortSignal },
) =>
  new Promise<{ url?: string; response?: unknown }>((resolve, reject) => {
    let percent = 0;
    const timer = setInterval(() => {
      if (options.signal?.aborted) {
        clearInterval(timer);
        reject(new DOMException('Aborted', 'AbortError'));
        return;
      }
      percent += Math.random() * 20 + 5;
      if (percent >= 100) {
        percent = 100;
        clearInterval(timer);
        if (Math.random() > 0.2) {
          resolve({ url: `https://example.com/${file.name}`, response: { ok: true } });
        } else {
          reject(new Error('模拟上传失败'));
        }
      }
      options.onProgress(Math.min(Math.round(percent), 100));
    }, 300);
  });

const value = ref<UploadFile[]>([]);
</script>

<template>
  <div class="demo-column">
    <Upload
      v-model:value="value"
      action="/upload"
      multiple
      :auto-upload="false"
      :request-upload="mockRequest"
    />
    <p class="demo-text">autoUpload=false：选中文件后进入「待上传」状态，点击「开始上传」手动触发。</p>
  </div>
</template>

Drag & Drop ​

With drag enabled the dashed dropzone accepts dropped files and clicks, highlighted on hover; accept and multiple constraints still apply.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Upload } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const requestUpload = (file: { name: string }) =>
  new Promise<{ url: string }>((resolve) => {
    setTimeout(() => resolve({ url: `/mock/${encodeURIComponent(file.name)}` }), 600);
  });

const doneCount = ref(0);

function handleChange() {
  doneCount.value += 1;
}
</script>

<template>
  <div class="demo-column">
    <Upload
      action="/upload"
      :request-upload="requestUpload"
      drag
      multiple
      accept="image/*,.pdf"
      @change="handleChange"
    />
    <p class="demo-text">
      {{
        isZh()
          ? `已完成上传：${doneCount} 个文件（accept 限定图片与 PDF）`
          : `Uploaded: ${doneCount} (images and PDF only)`
      }}
    </p>
  </div>
</template>

Contract Types ​

UploadFile

ts
interface UploadFile {
  uid: string
  name: string
  size: number
  type: string
  status: 'pending' | 'uploading' | 'done' | 'error' | 'cancelled'
  percent: number
  speed?: number
  remainingTime?: number
  response?: unknown
  url?: string
  raw?: File
}

Data structure of an uploaded file item; speed is the upload rate (bytes/s), remainingTime is the estimated remaining time (seconds).

RequestUploadFn

ts
type RequestUploadFn = (
  file: UploadFile,
  options: { action: string; onProgress: (percent: number) => void; signal?: AbortSignal }
) => Promise<{ url?: string; response?: unknown }>

Signature of a custom upload request function; signal supports cancelling the upload.

Notes ​

  • The default uses XMLHttpRequest; for SSR or non-browser environments, provide an implementation via requestUpload.
  • When beforeUpload returns false or a rejected promise, the file does not enter the upload flow.
  • maxCount limits the total file count (including uploaded); excess files are ignored. Files exceeding maxSize are marked as error and not uploaded.
  • When autoUpload=false, files enter pending state and require submit() or the "Start Upload" button; cancelled files must be removed and re-selected.

Accessibility ​

  • The upload trigger is a focusable native button; the disabled state passes through the disabled attribute.
