Skeleton 骨架屏 Data Display ​

Placeholder screen shown while data is loading, conveying structure before content is ready, with avatar placeholder and customizable row count.

Features ​

  • loading toggles between skeleton and real content; renders the default slot when false
  • avatar shows a leading avatar placeholder; rows sets the paragraph line count (coerced to a positive integer, defaults to 3)

When to Use ​

  • First-load of cards / lists / detail pages, or waiting for data on slow networks.

Examples ​

Each demo can be switched between Vue and React tabs for live interaction, with source code available per framework.

Loading Toggle ​

loading=true shows the skeleton; false renders the real content in the slot.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Skeleton, Button } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const loading = ref(true);
</script>

<template>
  <div class="demo-column">
    <Skeleton :loading="loading" :rows="3">
      <div class="demo-article">
        <h4>{{ isZh() ? '加载完成后的真实内容' : 'Real content after loading' }}</h4>
        <p>
          {{
            isZh()
              ? '这是一段从服务端获取的数据，loading 为 false 时替换骨架屏渲染。'
              : 'This is data fetched from the server; skeleton is replaced when loading is false.'
          }}
        </p>
      </div>
    </Skeleton>
    <Button size="sm" @click="loading = !loading">
      {{ isZh() ? (loading ? '加载完成' : '重新加载') : loading ? 'Finish loading' : 'Reload' }}
    </Button>
  </div>
</template>

<style scoped>
.demo-article h4 {
  margin: 0 0 8px;
}

.demo-article p {
  margin: 0;
  color: #6b7280;
}
</style>

Avatar Placeholder & Rows ​

avatar renders a circular avatar placeholder; rows controls the text line count.

Vue
<script setup lang="ts">
import { Skeleton } from '@xui-design/vue';
</script>

<template>
  <div class="demo-column">
    <Skeleton avatar :rows="2" />
    <Skeleton :rows="5" />
  </div>
</template>

API ​

@xui-design/core ComponentSpec · single contract, identical on both frameworks

Props ​

Props

PropTypeDefaultDescription
loadingbooleantrueLoading state (true renders the skeleton, false renders the slot content)
avatarbooleanfalseWhether to show the leading avatar placeholder
rowsnumber3Paragraph line count (coerced to a positive integer)
classNamestring—Custom class name appended to the root element
styleRecord<string, string>—Custom styles appended to the root element

Slots / Render Callbacks ​

Slots / Render Callbacks

Slot (Vue)Callback (React)Description
defaultchildrenReal content (rendered when loading=false)

Notes ​

  • Invalid rows values such as 0 or negatives are coerced to 1, guaranteeing at least one line.

Accessibility ​

  • The skeleton region is marked busy (aria-busy) so screen readers can sense that content is loading.
