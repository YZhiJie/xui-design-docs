Theming 主题定制 Guide ​

A three-layer theming system based on CSS variables: global light/dark switching, site-wide brand token customization, and per-component scoped overrides — both frameworks (@xui-design/vue / @xui-design/react) share the same runtime API.

How It Works ​

  • Light & Dark Themes: component styles only consume semantic tokens (--xui-color-*); the dark theme overrides all semantic colors through the [data-theme='dark'] selector. Switching themes simply toggles an attribute on <html>.
  • Global Tokens: setThemeTokens writes CSS variables as inline styles on <html>, cascading over the preset tokens — effective site-wide instantly, no refresh needed.
  • Component-Level Customization: write CSS variables directly on the root element style (both frameworks pass custom properties through style); the cascade applies only to that subtree.

Examples ​

Each demo can be switched between Vue and React tabs for live interaction, with source code available per framework.

Global Light & Dark Switching ​

setTheme writes <html data-theme> and every component switches semantic colors accordingly; toggleTheme alternates between light and dark.

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { getTheme, setTheme, toggleTheme } from '@xui-design/vue';
import { Alert, Button, Input, Switch, Tag } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const current = ref(getTheme());
const enabled = ref(true);
const text = ref('');

const updateText = () => {
  text.value = isZh() ? '跟随主题的输入框' : 'Themed input';
};
updateText();

const apply = (theme: 'light' | 'dark') => {
  setTheme(theme);
  current.value = getTheme();
};

const toggle = () => {
  current.value = toggleTheme();
};
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button type="primary" @click="apply('dark')">
        {{ isZh() ? '切换为暗色' : 'Switch to Dark' }}
      </Button>
      <Button @click="apply('light')">
        {{ isZh() ? '切换为浅色' : 'Switch to Light' }}
      </Button>
      <Button type="link" @click="toggle">
        {{ isZh() ? '往返切换' : 'Toggle' }}
      </Button>
      <Tag :type="current === 'dark' ? 'warning' : 'primary'">
        {{ isZh() ? '当前' : 'Current' }}：{{ current === 'dark' ? 'dark' : 'light' }}
      </Tag>
    </div>
    <Alert
      type="info"
      :title="isZh() ? '全局主题' : 'Global Theme'"
      :description="
        isZh()
          ? 'Alert / Button / Input / Switch 等组件颜色全部随主题联动。'
          : 'Alert / Button / Input / Switch colors all follow the theme.'
      "
    />
    <div class="demo-row">
      <Input v-model:value="text" style="width: 220px" />
      <Switch v-model:value="enabled" />
    </div>
  </div>
</template>

Global Brand Tokens (setThemeTokens) ​

setThemeTokens writes CSS variables to <html>, affecting every component site-wide; clearThemeTokens only removes tokens written by this API.

Vue
<script setup lang="ts">
import { Button, clearThemeTokens, setThemeTokens, Switch, Tag } from '@xui-design/vue';
import { ref } from 'vue';
import { isZh } from '../../../i18n';

const enabled = ref(true);

/** 品牌色预设：仅覆盖主色三态，其余 token 保持默认 */
const presets: Record<string, Record<string, string>> = {
  emerald: {
    '--xui-color-primary': '#10b981',
    '--xui-color-primary-hover': '#059669',
    '--xui-color-primary-active': '#047857',
  },
  amber: {
    '--xui-color-primary': '#f59e0b',
    '--xui-color-primary-hover': '#d97706',
    '--xui-color-primary-active': '#b45309',
  },
  rose: {
    '--xui-color-primary': '#f43f5e',
    '--xui-color-primary-hover': '#e11d48',
    '--xui-color-primary-active': '#be123c',
  },
};

const apply = (name: string) => setThemeTokens(presets[name]);
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button @click="apply('emerald')">{{ isZh() ? '翡翠绿' : 'Emerald' }}</Button>
      <Button @click="apply('amber')">{{ isZh() ? '琥珀橙' : 'Amber' }}</Button>
      <Button @click="apply('rose')">{{ isZh() ? '玫红' : 'Rose' }}</Button>
      <Button type="link" @click="clearThemeTokens()">
        {{ isZh() ? '恢复默认品牌色' : 'Reset to default brand color' }}
      </Button>
    </div>
    <div class="demo-row">
      <Button type="primary">{{ isZh() ? '主色按钮' : 'Primary button' }}</Button>
      <Tag type="primary">{{ isZh() ? '主色标签' : 'Primary tag' }}</Tag>
      <Switch v-model:value="enabled" />
    </div>
  </div>
</template>

Component-Level Theming ​

No API needed: write CSS variables directly on a component style; the cascade applies only to that subtree and takes precedence over global tokens.

Vue
<script setup lang="ts">
import { Button, Switch } from '@xui-design/vue';
import { isZh } from '../../../i18n';
</script>

<template>
  <div class="demo-column">
    <p class="demo-text">
      {{
        isZh()
          ? '在组件 style 上写 CSS 变量即可覆盖主题，仅作用于该组件子树：'
          : 'Write CSS variables in the component style to override the theme, scoped to that component subtree only:'
      }}
    </p>
    <div
      class="demo-row"
      style="
        --xui-color-primary: #7c3aed;
        --xui-color-primary-hover: #6d28d9;
        --xui-color-primary-active: #5b21b6;
      "
    >
      <Button type="primary">{{ isZh() ? '紫色子树' : 'Purple subtree' }}</Button>
      <Switch :value="true" />
    </div>
    <div class="demo-row" style="--xui-color-danger: #0ea5e9">
      <Button type="danger">{{
        isZh() ? 'danger 覆盖为天蓝' : 'danger overridden to sky blue'
      }}</Button>
      <Button type="primary">{{ isZh() ? '不受影响' : 'Unaffected' }}</Button>
    </div>
  </div>
</template>

API ​

The theming API is provided by @xui-design/shared (framework-agnostic implementation). @xui-design/vue and @xui-design/react re-export it under the same names with identical behavior.

Imperative Methods ​

Imperative Methods

MethodSignatureDescription
setTheme(theme: XuiTheme) => voidSwitches the light/dark theme (writes <html data-theme>); returns silently when the value is unchanged
getTheme() => XuiThemeReads the current theme; returns light in SSR / DOM-less environments
toggleTheme() => XuiThemeToggles between light and dark, returning the new theme
subscribeTheme(listener: (theme: XuiTheme) => void) => () => voidSubscribes to theme changes; returns an unsubscribe function
setThemeTokens(tokens: ThemeTokens) => voidWrites global theme tokens (CSS variables on <html>, effective site-wide); only accepts names starting with --; repeated calls merge, adding or overriding incrementally
clearThemeTokens() => voidRemoves all tokens written by setThemeTokens (does not affect data-theme or app-defined variables)

Contract Types ​

XuiTheme

ts
type XuiTheme = 'light' | 'dark';

Theme name (light is the default; dark is provided by the [data-theme=dark] block in tokens.scss).

ThemeTokens

ts
type ThemeTokens = Record<string, string>;

A set of theme tokens: keys are CSS custom property names (starting with --), values are the corresponding CSS values.
