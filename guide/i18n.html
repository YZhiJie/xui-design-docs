国际化 Internationalization 指南 ​

组件库内置中文（zh-CN）与英文（en-US）语言包：setLocale 一行切换全部组件文案，registerLocale 支持扩展任意语言，双端（@xui-design/vue / @xui-design/react）共享同一套运行时 API。

工作机制 ​

  • 文案分层：组件内置文案（Modal 按钮文本、Table 空态、DatePicker 面板标题与星期、Pagination / Breadcrumb / Skeleton / Select 的 aria 与占位符）统一从全局语言包读取；用户显式传入的文案 prop 始终优先。
  • 响应式切换：setLocale 通知所有订阅组件重渲染，Vue 端经 useLocaleData 组合式函数、React 端经 useSyncExternalStore 同步，已挂载组件即时更新。
  • 扩展语言：registerLocale 以组件分组提供部分语言包，组级浅合并到基底包上，可只翻译关心的分组；函数型字段（如 selectRow / titleFormat）便于适配不同语序。

内置文案清单（zh-CN） ​

  • Modal：确认 / 取消；Popconfirm：确定 / 取消
  • Table：暂无数据、全选、选择第 N 行
  • DatePicker：请选择日期、选择日期、上个月 / 下个月、YYYY 年 MM 月、日 一 二 … 六
  • Select：请选择（触发器占位）、搜索...（搜索框占位与 aria）
  • Pagination：分页 / 上一页 / 下一页；Breadcrumb：面包屑；Skeleton：加载中

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

内置语言切换（setLocale） ​

setLocale('zh-CN' / 'en-US') 即时切换全部组件的内置文案：Modal 按钮、Table 空态与行选择提示、DatePicker 面板标题与星期等。

Vue
<script setup lang="ts">
import { computed, ref } from 'vue';
import { getLocale, setLocale } from '@xui-design/vue';
import { Button, DatePicker, Modal, Table, Tag } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const current = ref(getLocale());
const visible = ref(false);

const columns = computed(() => [
  { key: 'name', title: isZh() ? '名称' : 'Name' },
  { key: 'age', title: isZh() ? '年龄' : 'Age' },
]);

const apply = (locale: string) => {
  setLocale(locale);
  current.value = getLocale();
};
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button type="primary" @click="apply('zh-CN')">{{ isZh() ? '中文' : 'Chinese' }}</Button>
      <Button @click="apply('en-US')">English</Button>
      <Tag type="primary">{{ current }}</Tag>
    </div>
    <div class="demo-row">
      <Button type="link" @click="visible = true">{{
        isZh() ? '打开 Modal' : 'Open Modal'
      }}</Button>
    </div>
    <Modal v-model:visible="visible" :title="isZh() ? '国际化演示' : 'i18n Demo'">
      {{
        isZh()
          ? '底部按钮文案随全局语言切换；点击确认或取消关闭。'
          : 'Footer button text follows the global locale; click OK or Cancel to close.'
      }}
    </Modal>
    <Table :columns="columns" :data-source="[]" />
    <DatePicker style="width: 240px" />
  </div>
</template>

注册自定义语言包（registerLocale） ​

registerLocale 按组件分组注册任意语言（组级浅合并，未覆盖分组回退注册时的基底包），setLocale 切换后立即生效。

Vue
<script setup lang="ts">
import { computed, ref } from 'vue';
import { getLocale, registerLocale, setLocale } from '@xui-design/vue';
import { Button, Modal, Popconfirm, Table, Tag } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const current = ref(getLocale());
const visible = ref(false);
const registered = ref(false);

const columns = computed(() => [
  { key: 'name', title: isZh() ? '名称' : 'Name' },
  { key: 'age', title: isZh() ? '年龄' : 'Age' },
]);

const registerJapanese = () => {
  registerLocale('ja-JP', {
    modal: { ok: 'OK', cancel: 'キャンセル' },
    popconfirm: { confirm: 'OK', cancel: 'キャンセル' },
    table: { empty: 'データがありません' },
  });
  registered.value = true;
  apply('ja-JP');
};

const apply = (locale: string) => {
  setLocale(locale);
  current.value = getLocale();
};
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button type="primary" :disabled="registered" @click="registerJapanese">
        {{
          registered
            ? isZh()
              ? '已注册 ja-JP'
              : 'ja-JP registered'
            : isZh()
              ? '注册日语语言包'
              : 'Register Japanese locale'
        }}
      </Button>
      <Button @click="apply('zh-CN')">{{ isZh() ? '回到中文' : 'Back to Chinese' }}</Button>
      <Tag type="primary">{{ current }}</Tag>
    </div>
    <div class="demo-row">
      <Button type="link" @click="visible = true">{{
        isZh() ? '打开 Modal' : 'Open Modal'
      }}</Button>
      <Popconfirm
        :content="isZh() ? '确认删除这条数据吗？' : 'Are you sure you want to delete this record?'"
      >
        <Button>{{ isZh() ? '删除' : 'Delete' }}</Button>
      </Popconfirm>
    </div>
    <Modal v-model:visible="visible" :title="isZh() ? '自定义语言包' : 'Custom Locale'">
      {{
        isZh()
          ? '注册后所有组件文案按新语言渲染，未覆盖的分组回退注册时的基底包。'
          : 'After registration, all component text renders in the new language; uncovered groups fall back to the base pack at registration time.'
      }}
    </Modal>
    <Table :columns="columns" :data-source="[]" />
  </div>
</template>

API ​

国际化 API 由 @xui-design/shared 提供（框架无关实现），@xui-design/vue 与 @xui-design/react 同名导出，行为完全一致。

命令式方法 ​

命令式方法

方法签名说明
setLocale(locale: string) => void切换当前语言；未注册的语言名静默忽略，值未变化时同样静默返回
getLocale() => string读取当前语言名（默认 DEFAULT_LOCALE）
getLocaleData() => XuiLocaleData读取当前语言包（返回稳定引用，切换语言时重建）；SSR / 无 DOM 环境同样可用
registerLocale(locale: string, data: XuiLocaleInput) => void注册或覆盖语言包：按组件分组浅合并到该语言的既有包上，未覆盖分组回退基底；无有效变更时不触发通知
subscribeLocale(listener: (locale: string) => void) => () => void订阅语言变化（回调收到新语言名），返回取消订阅函数
useLocaleData() => XuiLocaleData双端组件级 Hook（Vue 组合式 / React useSyncExternalStore），组件内读取语言包并响应切换

契约类型 ​

XuiLocaleData

ts
type XuiLocaleData = {
  modal: { ok: string; cancel: string };
  popconfirm: { confirm: string; cancel: string };
  table: { empty: string; selectAll: string; selectRow: (index: number) => string };
  pagination: { nav: string; prev: string; next: string };
  datePicker: {
    panel: string; prevMonth: string; nextMonth: string; placeholder: string;
    titleFormat: (year: number, month: number) => string; weekdays: string[];
  };
  skeleton: { loading: string };
  breadcrumb: { nav: string };
  select: { searchPlaceholder: string; searchAriaLabel: string; triggerPlaceholder: string };
};

完整语言包结构（按组件分组；函数型字段便于跨语序翻译）。

XuiLocaleInput

ts
type XuiLocaleInput = Partial<XuiLocaleData>;

registerLocale 的入参：只提供需要覆盖的分组，组内字段同为部分覆盖（浅合并）。

DEFAULT_LOCALE

ts
const DEFAULT_LOCALE = 'zh-CN';

默认语言常量；内置 zh-CN / en-US 两套语言包。

注意事项 ​

  • 默认语言为 zh-CN，内置文案与历史硬编码逐字一致，升级零行为变化；en-US 为内置英文包，均可通过 registerLocale 覆盖。
  • 组件显式传入的文案 prop（如 Modal 的 okText、Select 的 placeholder）永远优先于语言包；只有未提供时才回退语言包默认值。
  • 语言状态纯内存（不写 DOM），SSR 环境下所有 API 安全可用；切换语言即时通知全部已挂载组件重渲染，无需刷新。
  • registerLocale 采用组级浅合并：未覆盖的分组回退注册时的基底包；覆盖"当前语言"会立即重建缓存并通知，覆盖其他语言则静默生效到下次切换。
  • 语言切换影响整个文档站演示区的所有组件示例，离开本页后语言状态仍保留，可在 demo 中一键回到中文。
