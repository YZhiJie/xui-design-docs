浮层视口避让 Floating Positioning 指南 ​

Tooltip / Popconfirm / Select 等浮层组件双端共用 @xui-design/shared/floating 的纯逻辑避让模块：首选方位空间不足时自动翻转（flip），交叉轴溢出视口时自动钳制（shift），滚动与窗口 resize 时经 rAF 合并实时重算。

工作机制 ​

  • flip 方位翻转：计算首选方位与对侧的可用空间（如 spaceAbove = trigger.top - viewport.top），首选方位放不下且对侧更充足时翻转；两侧都不足时维持首选方位，避免抖动。
  • shift 偏移钳制：居中对齐后向视口安全区钳制（默认 ≥ 8px），交叉轴溢出时保持安全区不贴边 / 不裁切。
  • scroll / resize 实时重算：滚动事件以 capture 方式监听 window（祖先容器滚动也能收到），回调经 requestAnimationFrame 合并，一帧内最多执行一次。
  • 框架无关：resolveFloatingPosition 是纯函数，不读 DOM / 不写样式；DOM 测量与样式应用由双端适配层桥接，逻辑层不重复实现。
  • SSR 安全降级：无 window 时 getViewport 返回零矩形、bindViewportUpdate 返回空函数，不抛错。

代码演示 ​

每个 demo 均可切换 Vue / React 标签页实时交互，并可展开查看对应框架源码。

方位翻转（flip） ​

首选方位空间不足且对侧更充足时自动翻转：placement="top" 在视口顶部翻转到 bottom，placement="bottom" 在视口底部翻转到 top。

Vue
<script setup lang="ts">
import { ref } from 'vue';
import { Tooltip, Popconfirm, Button } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const topAnchor = ref<HTMLElement>();
const bottomAnchor = ref<HTMLElement>();

const scrollToTopEdge = () => {
  const el = topAnchor.value;
  if (!el) return;
  const rect = el.getBoundingClientRect();
  window.scrollTo({ top: window.scrollY + rect.top - 12, behavior: 'smooth' });
};

const scrollToBottomEdge = () => {
  const el = bottomAnchor.value;
  if (!el) return;
  const rect = el.getBoundingClientRect();
  window.scrollTo({
    top: window.scrollY + rect.top - window.innerHeight + rect.height + 12,
    behavior: 'smooth',
  });
};
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button type="primary" @click="scrollToTopEdge">
        {{ isZh() ? '滚动到视口顶部' : 'Scroll to viewport top' }}
      </Button>
      <Button @click="scrollToBottomEdge">
        {{ isZh() ? '滚动到视口底部' : 'Scroll to viewport bottom' }}
      </Button>
    </div>
    <p style="color: var(--docs-text-secondary, #888); font-size: 13px; margin: 8px 0 16px">
      {{
        isZh()
          ? '点击按钮将触发元素定位到视口边缘，再悬停 / 点击组件观察气泡自动翻转。'
          : 'Click a button to position the element at the viewport edge, then hover / click the component to see the popover auto-flip.'
      }}
    </p>
    <div ref="topAnchor" class="demo-row" style="padding: 8px 0">
      <Tooltip
        :content="isZh() ? '上方空间不足 → 翻转到下方' : 'Not enough space above → flip down'"
        placement="top"
      >
        <Button>{{ isZh() ? 'Tooltip top（近顶部）' : 'Tooltip top (near top)' }}</Button>
      </Tooltip>
      <Popconfirm
        :content="isZh() ? '确认删除此条记录？' : 'Confirm delete this record?'"
        placement="top"
        :confirm-text="isZh() ? '删除' : 'Delete'"
        :cancel-text="isZh() ? '取消' : 'Cancel'"
      >
        <Button type="danger">Popconfirm top</Button>
      </Popconfirm>
    </div>
    <div style="height: 50vh" />
    <div ref="bottomAnchor" class="demo-row" style="padding: 8px 0">
      <Tooltip
        :content="isZh() ? '下方空间不足 → 翻转到上方' : 'Not enough space below → flip up'"
        placement="bottom"
      >
        <Button>{{ isZh() ? 'Tooltip bottom（近底部）' : 'Tooltip bottom (near bottom)' }}</Button>
      </Tooltip>
      <Popconfirm
        :content="isZh() ? '底部确认提交？' : 'Confirm submit at bottom?'"
        placement="bottom"
        :confirm-text="isZh() ? '提交' : 'Submit'"
        :cancel-text="isZh() ? '取消' : 'Cancel'"
      >
        <Button type="primary">Popconfirm bottom</Button>
      </Popconfirm>
    </div>
  </div>
</template>

三组件共用避让逻辑 ​

Tooltip / Popconfirm / Select 双端共用 @xui-design/shared/floating 的翻转与钳制算法，不重复实现。

Vue
<script setup lang="ts">
import { computed, ref } from 'vue';
import { Tooltip, Popconfirm, Select, Button } from '@xui-design/vue';
import { isZh } from '../../../i18n';

const anchor = ref<HTMLElement>();

const scrollToTopEdge = () => {
  const el = anchor.value;
  if (!el) return;
  const rect = el.getBoundingClientRect();
  window.scrollTo({ top: window.scrollY + rect.top - 12, behavior: 'smooth' });
};

const options = computed(() =>
  Array.from({ length: 1000 }, (_, i) => ({
    label: isZh() ? `选项 ${i + 1}` : `Option ${i + 1}`,
    value: String(i + 1),
  })),
);
</script>

<template>
  <div class="demo-column">
    <div class="demo-row">
      <Button type="primary" @click="scrollToTopEdge">
        {{ isZh() ? '滚动到视口顶部' : 'Scroll to viewport top' }}
      </Button>
    </div>
    <p style="color: var(--docs-text-secondary, #888); font-size: 13px; margin: 8px 0 16px">
      {{
        isZh()
          ? 'Tooltip / Popconfirm / Select 三组件共用 @xui-design/shared/floating 的翻转与钳制逻辑。滚动到视口顶部后操作各组件，观察气泡 / 面板自动翻转到下方。'
          : 'Tooltip / Popconfirm / Select share the flip and clamp logic of @xui-design/shared/floating. Scroll to the viewport top, then interact with each component to see the popover / panel auto-flip downward.'
      }}
    </p>
    <div ref="anchor" class="demo-row" style="padding: 8px 0; gap: 16px">
      <Tooltip
        :content="isZh() ? 'Tooltip 共用避让逻辑' : 'Tooltip shares the avoidance logic'"
        placement="top"
      >
        <Button>Tooltip</Button>
      </Tooltip>
      <Popconfirm
        :content="isZh() ? 'Popconfirm 共用避让逻辑' : 'Popconfirm shares the avoidance logic'"
        placement="top"
        :confirm-text="isZh() ? '确定' : 'OK'"
        :cancel-text="isZh() ? '取消' : 'Cancel'"
      >
        <Button type="primary">Popconfirm</Button>
      </Popconfirm>
      <Select
        :options="options"
        virtual
        :placeholder="isZh() ? 'Select（虚拟滚动）' : 'Select (virtual scroll)'"
        style="width: 200px"
      />
    </div>
  </div>
</template>

API ​

浮层避让 API 由 @xui-design/shared/floating 提供（框架无关纯逻辑），Tooltip / Popconfirm / Select 双端适配层桥接调用，不直接暴露给应用层。

命令式方法 ​

命令式方法

方法签名说明
resolveFloatingPosition(trigger: FloatingRect, popper: FloatingRect, viewport: FloatingViewport, options: ResolveFloatingOptions) => FloatingPosition纯函数：输入触发器 / 浮层 / 视口的坐标矩形，输出最终方位（可能已翻转）与交叉轴平移量；不读 DOM、不写样式，便于单测。
getViewport() => FloatingViewport获取当前视口边界（整页可视区域）；SSR / 无 window 环境返回零矩形（计算结果等价于不翻转不偏移）。
bindViewportUpdate(callback: () => void) => () => void订阅视口变化（scroll capture + resize），回调经 rAF 合并（一帧最多一次）；返回解绑函数，组件卸载时调用即可彻底清理。

契约类型 ​

FloatingPlacement

ts
type FloatingPlacement = 'top' | 'bottom' | 'left' | 'right';

四方位联合类型，与 core 契约的 placement 对齐。

FloatingRect

ts
type FloatingRect = {
  top: number;
  right: number;
  bottom: number;
  left: number;
  width: number;
  height: number;
};

视口坐标矩形，可直接传 getBoundingClientRect() 的结果。

ResolveFloatingOptions

ts
type ResolveFloatingOptions = {
  placement: FloatingPlacement;
  gap?: number;        // 触发器与浮层间距，默认 8
  viewportPadding?: number; // 视口边缘安全区，默认 8
};

resolveFloatingPosition 的入参选项。

FloatingPosition

ts
type FloatingPosition = {
  placement: FloatingPlacement; // 实际方位（可能已翻转）
  shift: number;                // 交叉轴平移量（px）
};

避让计算结果：top/bottom 方位 shift 为水平位移（正向右移），left/right 方位为垂直位移（正向下移）。

注意事项 ​

  • CSS 包裹定位前提：浮层已通过 CSS 包裹方案随文档流跟随触发器，本模块仅输出避让修正；适配层必须先保证基础定位（居中 + gap）正确，再叠加 shift。
  • 翻转避免抖动：只在首选方位空间不足且对侧更充足时才翻转，两侧都不足时维持首选方位（由 shift 钳制兜底），不在边界附近来回翻转。
  • scroll 必须用 capture：滚动事件不冒泡，祖先容器滚动只能在捕获阶段于 window 收到；bindViewportUpdate 已用 capture，适配层不要改回冒泡监听。
  • 组件卸载必须解绑：bindViewportUpdate 返回的解绑函数须在 onBeforeUnmount / useEffect cleanup 中调用，否则监听泄漏、回调引用已卸载 DOM。
  • overflow: hidden 祖先仍可能裁剪面板：气泡采用 CSS 包裹定位而非 portal，父容器存在 overflow 裁剪时需在布局层面规避。
